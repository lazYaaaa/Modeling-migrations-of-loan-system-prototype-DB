## 🔐 СИСТЕМА БЛОКИРОВОК (главная фишка)

### Как это работает:

```
1. Сотрудник видит заявку со статусом 🔓 (свободна)
2. Нажимает "Обработать заявку"
3. API:
   - Проверяет есть ли блокировка
   - Если есть → ошибка "уже обрабатывается"
   - Если нет → INSERT в application_locks
   - Устанавливает timeout на 30 минут
4. Сотрудник видит таймер ⏱️ (осталось XX минут)
5. Редактирует заявку
6. Нажимает "Одобрить" или "Отклонить"
7. API:
   - Создает договор (если одобрено)
   - DELETE из application_locks
   - Обновляет статус заявки
8. Другие сотрудники теперь видят обновленный статус
9. Если забыть → через 30 минут автоматически разблокируется
```

### Таблица блокировок (SQL):
```sql
CREATE TABLE application_locks (
    lock_id SERIAL PRIMARY KEY,
    application_id INTEGER UNIQUE,      -- какую заявку
    locked_by INTEGER,                   -- кто заблокировал
    locked_at TIMESTAMP,                 -- когда заблокировал
    timeout_at TIMESTAMP                 -- когда разблокируется
)
```
