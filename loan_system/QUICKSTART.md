# QUICKSTART - Быстрый старт за 10 минут

## 📋 Предварительные требования

- ✓ PHP 7.4+
- ✓ PostgreSQL 12+
- ✓ Браузер (Chrome, Firefox, Safari, Edge)

## 🚀 Шаг за шагом

### Шаг 1: Подготовка PostgreSQL (2 минуты)

```bash
# Откройте терминал и подключитесь к PostgreSQL
psql -U postgres

# Создайте новую базу данных
CREATE DATABASE loan_system;

# Выйдите из psql
\q
```

### Шаг 2: Инициализация БД (2 минуты)

```bash
# Перейдите в папку приложения
cd c:\tt\lab_bd\loan_system

# Создайте таблицы
php setup_db.php

# Создайте демо-данные
php create_demo_data.php
```

### Шаг 3: Запуск приложения (1 минута)

```bash
# Перейдите в папку frontend
cd c:\tt\lab_bd\loan_system\frontend

# Запустите встроенный PHP сервер
php -S localhost:8000
```

### Шаг 4: Вход и использование (5 минут)

1. **Откройте браузер**
   - Перейдите на: http://localhost:8000

2. **Введите учетные данные**
   - Логин: `user_1` (или `user_2`, `user_3`, ..., `user_10`)
   - Пароль: любой (не требуется в демо)
   - Нажмите "Войти"

3. **Вы в системе!**
   - Нажмите на "Заявки" в боковом меню
   - Нажмите "Открыть" на одной из заявок
   - Нажмите "Обработать заявку"
   - Отредактируйте сумму (опционально)
   - Выберите "Одобрить" или "Отклонить"

## 🎯 Основные функции

### 1. Просмотр заявок 📋
- Вкладка "Заявки" → видите все кредитные заявки
- Зеленый замок 🔓 = можно обрабатывать
- Красный замок 🔒 = уже обрабатывает другой сотрудник

### 2. Обработка заявки 📝
- Нажимаем "Открыть" → окно заявки
- Нажимаем "Обработать заявку" → система блокирует для вас
- Редактируем если нужно → Одобряем или Отклоняем
- Автоматический таймер: 30 минут на принятие решения

### 3. Просмотр клиентов 👥
- Вкладка "Клиенты" → список всех клиентов
- Нажмите на строку "Просмотр" для деталей

### 4. Справочник продуктов 💰
- Вкладка "Продукты" → все кредитные продукты
- Показывает: сумму, срок, процентную ставку

## 🔒 Система блокировок объяснение

**Проблема:** Что если два сотрудника одновременно обрабатывают одну заявку?

**Решение:** Система блокировок
- Первый сотрудник нажимает "Обработать" → заявка блокируется
- Второй сотрудник видит: "Заявка обрабатывается Ивановым" (обработать не может)
- После того как первый закончит (нажмет Одобрить/Отклонить) → блокировка снимается
- Таймер: если сотрудник забудет, через 30 минут заявка автоматически разблокируется

## 🔧 Решение частых проблем

### Ошибка: "Could not connect to server"
```
Проверьте:
1. PostgreSQL запущен?
   sudo systemctl status postgresql
   
2. Параметры в api/config/database.php правильные?
   db_host = 'localhost'
   db_port = 5432
   db_name = 'loan_system'
   db_user = 'postgres'
   db_password = 'ваш_пароль'
```

### Ошибка: "Class 'PDO' not found"
```
Установите расширение:
Windows: php.ini → uncomment extension=pdo_pgsql
Linux: sudo apt-get install php-pgsql
Mac: brew install php@8.0 --with-pgsql
```

### Ошибка 404 при открытии заявки
```
Это нормально для первого запуска.
Перезагрузите страницу (F5) или очистите кэш браузера.
```

### Таблица "application_locks" не найдена
```
Переустановите через:
php setup_db.php
```

Если что-то не работает:

1. **Проверьте логи**
   ```bash

   tail -f /var/log/php-fpm.log
   ```

2. **Проверьте консоль браузера** (F12 → Console)

3. **Проверьте простые вещи**
   - PHP запущен?
   - PostgreSQL запущен?
   - Прав доступа хватает?
   - Имя БД совпадает?
